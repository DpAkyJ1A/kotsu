# Architecture decision records

Short notes on decisions that are costly to reverse, choose between real alternatives, or would surprise
someone reading the code. Routine choices don't get one.

- One file per decision, `NNNN-kebab-title.md`, numbered in the order written.
- One page at most: Context, Decision, Consequences.
- Status is Accepted, or Superseded by NNNN. A superseded record stays, so the history reads in order.
- A record lands in the same pull request as the code it explains.

```md
# NNNN. Title

- Date: YYYY-MM-DD
- Status: Accepted

## Context

## Decision

## Consequences
```
